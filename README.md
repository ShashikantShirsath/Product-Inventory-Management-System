# Inventory Management System - Backend

## Project Description

This is the backend of the Inventory Management System built using Node.js, Express, and MongoDB Atlas (cloud database).

It provides RESTful APIs for user authentication and product management. The system uses JWT-based authentication to secure protected routes.

The backend handles product CRUD operations, filtering, sorting, and low-stock logic.

## Technology Stack

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JSON Web Token (JWT)
- bcrypt.js
- CORS
- dotenv

---

## Features Implemented

- JWT-based Authentication
- Secure Login API
- Protected Product Routes
- Create Product
- Get All Products (with search, filter, sort)
- Update Product
- Delete Product
- Low Stock Detection (Quantity < 10)
- CORS Enabled
- Authorization Middleware
- Cloud Database
